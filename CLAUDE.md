## Development Commands

- `npm run dev` - Start development server with hot module replacement
- `npm run build` - Build for production
- `npm run lint` - Run ESLint for code quality checks
- `npm run preview` - Preview production build locally
- `npm run sync` - Generate workspace index + events.ics, then sync artwork to Cloudflare R2

## Hosting

- **Cloudflare Pages** serves the React SPA at `ziedritz.art` (auto-deploys on push to `master`)
- **Cloudflare R2** serves artwork files at `media.ziedritz.art` (synced via `npm run sync`)
- Domain registered on cosmotown.com, DNS managed by Cloudflare

## Architecture Overview

This is a React frontend for an art portfolio website built with:
- **Vite** for build tooling and development server
- **Mantine** UI library with dark theme as default
- **React Router** with HashRouter for client-side routing
- **date-fns** for date formatting and manipulation

### Data Flow

The application fetches art project data from a static `workspace-index.json` hosted on Cloudflare R2 via the `useWorkspace` hook. This JSON is generated locally by `scripts/generate-workspace-index.js` which scans `/mnt/d/artwork/workspace/`. The hook processes the response to:
- Parse project dates and format them consistently
- Clean title formatting (removes leading numbers)
- Sort projects by date (newest first)
- Group projects by year/month

All artwork images, videos, and .clip files are served from R2 (`media.ziedritz.art`). The R2 base URL is configured in `src/config.js`.

### Routing Structure

- `/` - Home gallery page
- `/aspirations` - Aspirations showcase
- `/art-trends-calendar` - Art trends calendar view
- `/daily-tracker` - Daily practice tracker (fetches from Google Sheets)
- `/:year/:month/:slug` - Individual project pages

### Sync Workflow

`npm run sync` runs `scripts/sync.js` which:
1. Scans `/mnt/d/artwork/workspace/` and generates `workspace-index.json` (placed in workspace root, synced to R2)
2. Generates `public/static/events.ics` from `public/static/events.json` (served by Pages — commit and push if events changed)
3. Runs `rclone.exe sync` to push artwork + index to R2

The rclone remote `r2` is configured locally with Cloudflare R2 S3-compatible credentials. The script converts WSL paths to Windows paths for `rclone.exe`.

### Important Files

- `src/config.js` - R2 base URL constant
- `src/hooks/useWorkspace.js` - Central data fetching and processing logic
- `src/hooks/useDailyTracker.js` - Fetches daily practice data from Google Sheets CSV
- `src/App.jsx` - Main routing and navigation structure
- `scripts/sync.js` - Sync entrypoint (generates index, generates ics, rclone to R2)
- `scripts/generate-workspace-index.js` - Scans artwork directory, outputs JSON matching frontend expectations
- `scripts/generate-events-ics.js` - Converts events.json to static .ics calendar file

### Static Assets

The `public/static/` directory contains:
- `aspirations/` - Artist inspiration images (served by Pages)
- `events.json` - Art trend calendar event data
- `events.ics` - Generated iCalendar file (generated by sync, committed to repo)

The artwork workspace at `/mnt/d/artwork/workspace/` is organized as `YYYY MM/project-name DD/` directories containing images, .clip files, timelapses, and notes.
